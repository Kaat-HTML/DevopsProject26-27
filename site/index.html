Mijn homelab

Schoolproject DevOps 2026-27, door Lucas

Waar gaat dit over?

Dit is mijn eigen kleine serveromgeving. Alles draait in Docker op mijn eigen pc en wordt met één docker-compose.yml opgestart. Ik heb vooral diensten gekozen die ik zelf wil gebruiken: een reisdagboek, een plek voor mijn 2FA-codes, een lijst met games die ik nog wil spelen en nog wat andere dingen.

De diensten staan achter een reverse proxy (Caddy). Van buitenaf is alleen Caddy bereikbaar, de rest praat onderling via Docker-netwerken. Voor toegang van buitenaf gebruik ik Tailscale, dus alleen mijn eigen apparaten komen erbij.

Mijn diensten

Dienst Waarvoor ik hem gebruik
AirTrail Bijhouden van de vluchten die ik gemaakt heb. Gebruikt PostgreSQL.
2FAuth Mijn 2FA-codes, zodat ze niet in een app van een ander bedrijf staan.
Game Backlog Zelf geschreven (Python en Flask, met SQLite). Een lijst van games die ik nog wil spelen, bezig ben of uitgespeeld heb.
Discount Bandit Prijzen van producten volgen, zodat ik zie wanneer iets in de aanbieding is.
AdGuard Home DNS-filter dat reclame en trackers blokkeert.
Uptime Kuma Controleert of al de rest online is.
Deze pagina Een statische pagina in nginx, om de setup uit te leggen.

Hoe het in elkaar zit

bezoeker
   |
   | HTTPS (Tailscale)
   v
Caddy (reverse proxy)
   |
   |  netwerk "proxy"
   +-- infopagina (nginx)
   +-- AirTrail --------------+
   +-- 2FAuth                 |  netwerk "backend"
   +-- Game Backlog           |  (intern, geen toegang van buitenaf)
   +-- Discount Bandit        |
   +-- AdGuard Home           +-- PostgreSQL
   +-- Uptime Kuma

De PostgreSQL-database van AirTrail staat alleen in het netwerk backend. Dat netwerk is als internal ingesteld, dus er is geen weg naar buiten of naar binnen, behalve via AirTrail zelf.

Hoe ik ermee werk

Alle configuratie en code staan in Git. Wachtwoorden en sleutels staan in een .env-bestand dat niet in de repository zit; in .env.example staat welke variabelen er nodig zijn. Waar het kan, heb ik de versie van een image vastgezet, zodat een update niet ongemerkt iets kapotmaakt.

Wat nog moet

Dit project is nog bezig. Dit staat nog op mijn lijst:

  • Inloggen voor alle diensten via één identity provider
  • Back-ups van de databases en volumes, en testen of terugzetten werkt
  • Automatisch uitrollen bij een push naar Git
  • Alle images op een vaste versie zetten (een paar staan nog op latest)
